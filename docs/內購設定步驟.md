# 內購設定步驟

這份是給多米在 App Store Connect 照著點的。做完之後，蒜日子主題頁的「暫時無法購買」會變成「解鎖完整版」加價格。

寫於 2026-11-16，步驟對過 Apple 的說明頁。App Store Connect 的選單名稱偶爾會改，找不到某個按鈕就截圖給我。

全部在 https://appstoreconnect.apple.com 做，用你的開發者帳號登入。

## 一、簽付費 App 協議

沒簽這份，後面建的商品 app 抓不到，沙盒也測不了。

1. 首頁點「商務」（Business）。
2. 找到「付費 App」（Paid Apps）那份協議，按檢視並同意。只有帳號持有人能簽。
3. 接著填三樣：銀行帳戶、稅務表單、聯絡人。
4. 填完狀態會變成「處理中」，Apple 審核銀行資料要一到幾天。狀態變成「有效」才算完成。

這一步最花時間，先做。

## 二、建商品

1. 點「App」，選蒜日子。
2. 左邊選單「營利」（Monetization）底下點「App 內購買項目」（In-App Purchases）。
3. 按「+」新增。
4. 類型選「非消耗性項目」（Non-Consumable）。選錯不能改，要刪掉重建。
5. 填兩個欄位：
   - 參考名稱：`蒜日子完整版`。只有你在後台看得到。
   - 產品 ID：`com.domyweb.countingdays.full`
6. 按「建立」。

產品 ID 一個字都不能差，大小寫也算。建好之後不能改，刪掉之後這個 ID 也不能再用，所以貼上之前多看一眼。

## 三、填價格與說明

建好會進到商品頁，往下填：

1. 價格：按「加入定價」，選基準國家（台灣）和價格。價格由你定，程式會自動顯示你選的金額。
2. 供應狀況：選要在哪些國家賣。
3. 家人共享：要不要開由你決定。開了之後一個人買，家人群組都能用。開了不能關。
4. App Store 本地化版本：按「加入本地化版本」，語言選繁體中文，填：
   - 顯示名稱：使用者付款視窗上看到的名字，例如 `蒜日子完整版`
   - 描述：一句話說買了有什麼，例如 `六款主題配色`
5. 審查資訊：
   - 截圖：上傳一張主題頁的截圖，讓審查員知道購買按鈕在哪。這張我可以從模擬器截給你。
   - 審查備註：寫怎麼走到購買頁，例如 `選單 → 設定 → 主題 → 解鎖完整版`
6. 按「儲存」。

存完狀態會是「準備提交」。這時候 TestFlight 就抓得到商品了，不用等審查。改過的資料最多要一小時才會生效。

## 四、在手機上試買

從 TestFlight 裝的版本，買東西不會真的扣款。

1. TestFlight 更新到最新版的蒜日子。
2. 選單 → 設定 → 主題。底下的按鈕應該變成「解鎖完整版」加你定的價格。
3. 還是「暫時無法購買」的話，先確認第一節的協議狀態是不是「有效」，再等一小時。
4. 點一款上鎖的主題試看，再按解鎖，照畫面完成購買。
5. 買完六個鎖頭應該都不見，剛才試看的那款直接套用。

要驗的還有這幾項：

- 把 app 滑掉重開，付費主題還在。
- 刪掉 app 重裝，進主題頁按「恢復購買」，鎖頭消失。
- 買之前把手機切到飛航模式進主題頁，按鈕應該是「暫時無法購買」，不會當掉。

## 五、沙盒測試帳號（想重複測才需要）

用自己的 Apple 帳號買過一次之後，就沒辦法再測「還沒買」的狀態。要重複測就建一個沙盒帳號。

1. App Store Connect 首頁點「使用者與存取權限」。
2. 上面點「沙盒」（Sandbox）。
3. 按「+」新增測試人員。電子郵件要用一個沒註冊過 Apple 帳號的信箱。名字、信箱、密碼建好之後不能改。
4. 手機上：設定 → 開發者 → 最底下「沙盒 Apple 帳號」，用剛建的帳號登入。找不到「開發者」這一項的話，要先到 設定 → 隱私權與安全性 開啟開發者模式。

沙盒帳號的購買紀錄可以在 App Store Connect 的沙盒頁清掉，清掉就能再測一次沒買的狀態。

## 六、正式上架時

第一個內購項目要跟著一個新的 app 版本一起送審，不能單獨送。

送審 app 的時候，在版本頁的「App 內購買項目與訂閱」那一區，把「蒜日子完整版」加進去再提交。
