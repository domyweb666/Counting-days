## 備註（貼這段）

```
SuanRiZi is a month calendar that reads the events already in the iPhone Calendar (iCloud, Google or any account added in iOS Settings) and shows them in a layout that is easier to read on a phone. There is no account and no server. The app UI is Traditional Chinese.

How to test
1. On first launch, an explanation screen tells why calendar access is needed. Tap the green button (繼續) and allow full access. The app needs full access because it shows existing events and writes new events back to the system calendar.
2. If the test device has no events, add a few in the built-in Calendar app, or create one in SuanRiZi with the + button at the bottom right.
3. Tap a day to expand it. Long-press an event for pin / short name / countdown / share / edit.
4. The menu button (top left) switches between agenda, day, 3-day, week and month views, and opens Settings.

In-app purchase
- One non-consumable product, com.domyweb.countingdays.full (蒜日子完整版). No subscription.
- It unlocks 6 color themes, 2 extra calendar styles (週條, 主事件), unlimited countdowns and custom category colors.
- Where to find it: Settings (設定) > 主題 (Theme), or Settings > 月曆樣式 (Calendar style). Locked items can be previewed by tapping them; the purchase button (解鎖完整版) and Restore Purchases (恢復購買) are at the bottom of both pages. Settings also has a 購買 section.

Network use
- Weather is off by default. When turned on, the app sends only the fixed coordinates of the county the user picks to WeatherKit.
- The place search on the new event screen uses MapKit.
- Nothing else leaves the device unless the user taps Share.

The attached video walks through the permission prompt, the main calendar, adding an event with a location, the other views, and where the in-app purchase is.
```

### 中文對照

蒜日子是一個月曆，讀 iPhone 行事曆裡原本的行程（iCloud、Google 或任何加在 iOS 設定裡的帳號），用手機上比較好讀的方式排出來。沒有帳號、沒有伺服器。介面是繁體中文。

測試方式：第一次打開有一頁說明為什麼要行事曆權限，按綠色按鈕「繼續」並允許完整取用。需要完整取用，是因為要顯示原本的行程，新增的行程也要寫回系統行事曆。測試機沒有行程的話，在內建行事曆加幾筆，或在蒜日子右下角按＋新增。點一天會展開；長按行程有置頂、短名、倒數日、分享、編輯。左上角選單可以切換時間表、天、3 天、週、月，也能進設定。

內購：一個非消耗性商品 `com.domyweb.countingdays.full`（蒜日子完整版），沒有訂閱。內容是六款主題、兩種月曆樣式（週條、主事件）、倒數日不限數量、類別自訂顏色。在「設定 → 主題」或「設定 → 月曆樣式」，上鎖的可以點一下試看，最下面有「解鎖完整版」和「恢復購買」。設定裡也有「購買」那一區。

網路：天氣預設關閉，打開後只把選的縣市的固定座標送給 WeatherKit。新增行程的地點搜尋用 MapKit。除此之外，使用者沒按分享就不會送出任何東西。

附的影片從權限視窗開始，示範月曆主畫面、新增有地點的行程、其他檢視，以及內購在哪裡。
