# 手機驗收清單

對應 `main` 的 commit `fe2455e`（2026-11-15）。涵蓋第 1 到 5 片、選單鈕、新手引導第二版、天氣設定。

照順序做，大約 30 到 40 分鐘。每一項左邊是你要做的動作，「→」後面是應該看到的樣子。不一樣的地方記下編號，截圖給 Claude。

有些項目寫「記下來就好」，那是沒有標準答案、要你憑感覺判斷順不順的地方。

## 0. 先準備

驗之前在 iPhone 內建的「行事曆」加幾筆，不然月曆是空的，很多項目驗不到。

- [ ] 0-1 今天加一筆有時間、有地點的行程（例：下午 3 點「看牙」，地點隨便填）
- [ ] 0-2 今天再加一筆沒有地點的行程（例：晚上 8 點「回信」）
- [ ] 0-3 後天加兩筆，時間重疊（例：10 點到 12 點、11 點到 12 點）
- [ ] 0-4 下週加一筆全天、連續三天的行程（例：「出差」）
- [ ] 0-5 上週隨便加一筆
- [ ] 0-6 加一筆標題超過 6 個字的行程（例：「跟出版社開線上會議」）

如果這支手機已經裝過蒜日子，先刪掉重裝，才驗得到第一次打開的流程。

## A. 第一次打開

- [ ] A-1 打開 app → 先看到一頁說明，寫為什麼需要行事曆、行程不會離開手機，下面一顆「繼續」
- [ ] A-2 按「繼續」→ 跳出 iPhone 的權限視窗
- [ ] A-3 選「允許完整取用」→ 進到月曆，看得到 0 加的那些行程

## B. 新手引導

引導不會自己開始（第 18 片改的）。進到月曆先看到自己的行程，點標題列下面的小卡才開始。引導期間月曆上顯示的是範例行程，不是你的。

- [ ] B-0a 進到月曆等 5 秒 → 月曆上是 0 加的那些行程，畫面沒有變暗。標題列下面有一張小卡「第一次用？花一分鐘看怎麼用」，右邊一個 ✕，沒有蓋住月曆
- [ ] B-0b 點小卡的字 → 小卡收起來，引導開始
- [ ] B-1 畫面變暗，選單鈕（三條線）被照亮，下面一張說明卡，字一個一個打出來
- [ ] B-2 字還在打的時候按「知道了」→ 整段字一次出現，沒有跳到下一步
- [ ] B-3 再按「知道了」→ 洞滑到月曆區，說明卡縮成一條，上面一排「月、時間表、週、3 天、天」
- [ ] B-4 按「下一個」四次 → 月曆區依序變成時間表、週、3 天、天，每張說明不同。最後一張按鈕變成「知道了」
- [ ] B-5 直接點那排名稱裡的「月」→ 跳回月
- [ ] B-6 一路按到下一步 → 今天那一格被照亮，說明卡寫「換你點點看」，沒有「知道了」
- [ ] B-7 點洞以外的任何地方 → 沒反應
- [ ] B-8 點被照亮的今天 → 當天行程展開，洞移到那塊行程上。這一步和後面兩步要等你按了才走，不會自己跳掉
- [ ] B-9 按「知道了」→ 第一件行程被照亮，過一下旁邊出現一個選單的樣子（置頂、短名、倒數日、編輯）
- [ ] B-10 按「知道了」→ 月曆區依序看彈性週、清單、週條、主事件四種樣式
- [ ] B-11 最後一步照亮月份標題，按「知道了」→ 引導淡出
- [ ] B-12 引導結束後 → 月曆變回你自己的行程，範例行程（錄影、牙醫、台南行）都不見了
- [ ] B-13 每一步的洞有沒有準確套在目標上，有沒有歪掉或蓋到別的東西。記下來就好
- [ ] B-14 洞滑過去、打字的速度順不順。記下來就好

## C. 標題列與選單鈕

- [ ] C-2 點選單鈕 → 跳出選單：月、時間表、週、3 天、天（目前那個有打勾），下面是搜尋、設定

- [ ] C-4 選回「月」

## E. 四種月曆樣式

- [ ] E-1 選「清單」→ 上面小月曆只有色塊沒有字，下面「接下來」一張張卡片，右邊寫「今天」「N 天後」
- [ ] E-2 選「週條」→ 沒事的日子縮成窄條，有事的撐開成卡片並列出完整標題
- [ ] E-3 選「主事件」→ 每天只有一個色塊加字，其他行程是小方塊

## F. 時間表與時間軸

- [ ] F-3 選單 → 週 → 七欄時間軸，打開時捲在現在時間附近，今天那欄有一條綠色橫線

## G. 新增、修改、刪除

- [ ] G-2 填標題按「加入」→ 回到月曆，新行程出現在今天

## 已知還沒做或有限制的

這些看到了不用回報。

- 天氣還沒做完，設定裡的天氣區先藏起來了。
- 週檢視一欄只放得下三四個字，標題會被切。
- 引導裡的長按選單是畫出來的示意，不是 iPhone 自己的選單。
- 引導說明卡的頭像暫時用 app 圖示。
- 節氣個別年份可能差一天，還沒有逐年對過氣象署資料。
- 週條樣式下，今天如果被併進一整塊跨日行程，引導第 3 步會自動跳過。
