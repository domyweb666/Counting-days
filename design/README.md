# 設計檔

這裡是設計畫布的原始檔。每個 `.dc.html` 是一張 390×844 的手機畫板，`canvas.json` 記錄畫板在畫布上的位置。

這些檔案依賴設計畫布提供的 `support.js`，直接用瀏覽器打開不會顯示內容。它們放在這裡是當作實作參考：版面、尺寸、顏色都寫在每個元素的行內樣式裡，`F-Switch.dc.html` 底部的腳本有主事件挑選、週收合、週條合併等完整邏輯。

| 檔案 | 畫板 | 內容 |
|---|---|---|
| `Main.dc.html` | A 彈性週 | 沒事的週壓扁、有事的週長高；待辦收成日期旁的小數字 |
| `B-MiniList.dc.html` | B 上格下列 | 小月曆只有色塊，下面「接下來」清單 |
| `C-WeekStrips.dc.html` | C 週條 | 一週一橫條，有事的日子撐開 |
| `D-BusyMonth.dc.html` | D 滿載 · 月檢視 | 每天一件主事件加小色塊 |
| `E-BusyDay.dc.html` | E 滿載 · 點開一天 | 靜態示意：那一天在週內橫向撐開成時間表 |
| `F-Switch.dc.html` | F 切換式原型 | 可互動：四種呈現方式切換，點一天展開 |

## 資料說明

畫板裡的事件、日期、地點全部是示範用的假資料（2029 年 4 月），不是任何人的真實行程。沒有時間的事件是刻意留空，用來示範時間欄空白時的樣子。

## 與規格不同的地方

- E 畫板把選到的那天在週內橫向撐開；F 原型與規格改成在該週下方展開面板，四種呈現方式才能共用同一種時間表。以規格為準。
- A 畫板日期旁的待辦件數（·13、·30）在規格裡排到第一版之後。
